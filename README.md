# KrysukEngine

## Temat projektu
Aplikacja desktopowa **KrysukEngine** – lekki, przenośny silnik gier komputerowych z wbudowanym renderem i architekturą ECS (Entity-Component-System), skierowany do deweloperów gier.

## Krótka wizja systemu
KrysukEngine to aplikacja desktopowa dla twórców gier, która pozwala na szybkie tworzenie gier 3D bez konieczności budowania silnika od podstaw. Dzięki wdrożonemu paradygmatowi ECS umożliwia elastyczny, niezależny rozwój komponentów oraz łatwe rozszerzanie funkcjonalności. Aplikacja zawiera zintegrowany render, wsparcie dla popularnych formatów modeli 3D i tekstur oraz zapewnia przenośność między platformami Linux i Windows. Dla graczy gwarantuje wysoką wydajność i możliwość uruchamiania gier na różnych platformach.
